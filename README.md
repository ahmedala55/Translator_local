# الوافي — ترجمة عربية وإنكليزية

الترجمة من الإنكليزية إلى العربية فقط. واجهة Next.js وNode.js مع محرك Argos Translate.

## إعداد نسخة جديدة

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe setup_models.py
cd web
npm ci
npm run dev
```

على Linux استخدم `.venv/bin/python` بدلاً من `.venv/Scripts/python.exe`. لا تُرفع النماذج وبيئة Python إلى GitHub؛ يقوم `setup_models.py` بتنزيل نموذج الإنكليزي إلى العربي وتهيئة ملفات تقسيم الجمل فقط. الخطوط مضمّنة في `web/app/fonts`.

## النشر على Vercel

1. استورد المستودع، واختر **Root Directory: `web`** وFramework: **Next.js**. اترك أوامر البناء الافتراضية.
2. شغّل محرك Argos على خادم يدعم Docker/Python باستخدام `Dockerfile` الموجود بجذر المستودع. يستمع إلى متغير `PORT`، وافتراضياً المنفذ 8000. يحتاج البناء إلى الإنترنت لتنزيل نموذج اللغة، ومساحة وذاكرة كافية لتشغيله.
3. ضع سراً عشوائياً طويلاً في `ARGOS_API_KEY` على خادم Argos.
4. في إعدادات Vercel أضف `ARGOS_API_URL` كرابط HTTPS لخادمك ينتهي بـ `/translate`، وأضف `ARGOS_API_KEY` بنفس القيمة. لا تستخدم بادئة `NEXT_PUBLIC_` للمفتاح.
5. انشر الواجهة. من دون هذين الإعدادين تظهر الواجهة لكن الترجمة لا تعمل على Vercel.

يمكن فحص جاهزية الخادم عبر `/health`. خدمة الترجمة تتطلب المفتاح ولا تسمح إلا باتجاه `en → ar`. ملفات `.env` الحقيقية مستثناة من Git؛ المثال موجود في `web/.env.example`.

البنية المحلية تشغّل Python من Node.js؛ إعداد Vercel يستخدم خدمة Argos عبر HTTPS بدلاً من الاعتماد على بيئة Python الموجودة على جهازك. عند النشر تنتقل النصوص إلى خادم Argos الذي تحدده، ولذلك يحتاج الزائر إلى الإنترنت. لم يُنشر المشروع أو محرك الترجمة على أي استضافة بعد.

واجهة Next.js تعمل على Node.js، مرتبطة بمحرك Argos المحلي عبر عملية Python مستمرة. النماذج تبقى محمّلة بين الطلبات، والنصوص لا تذهب إلى خدمة ترجمة خارجية.

## التشغيل

من `F:\Transletor` شغّل `./start.ps1`، أو ادخل إلى مجلد `web` وشغّل `npm run dev`، ثم افتح http://localhost:3000.

للإنتاج المحلي: داخل `web` شغّل `npm run build` ثم `npm start`.

المتطلبات المثبتة: Node.js، بيئة Python في `.venv`، ونموذج `en → ar` داخل `models`. يمكن إعادة تثبيت حزم الواجهة بواسطة `npm ci` من مجلد `web`. لا يحتاج التشغيل بعد التثبيت إلى الإنترنت.

## الاستخدام

اكتب النص ثم اضغط «ترجم النص» أو Ctrl+Enter. الترجمة من الإنكليزية إلى العربية فقط. الحد ٥٠٠٠ حرف للطلب، مع نسخ الترجمة ومسح النص.

أول طلب قد يستغرق وقتاً إضافياً لتحميل المحرك. التشغيل الافتراضي متاح على الجهاز نفسه فقط. الواجهة لا تضيف سجلاً دائماً للنصوص. عند نقل المشروع يجب نقل نماذج اللغات وإعداد بيئة Python للجهاز الجديد؛ لا يمكن تشغيل Argos Python داخل استضافة صفحات ثابتة.
